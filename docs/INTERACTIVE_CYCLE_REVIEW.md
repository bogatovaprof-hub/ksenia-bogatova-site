Заменён только этот компонент и связанная с ним логика. Сохранены четыре смысловых этапа, исходные подробные описания, заголовок раздела, распределение ролей и вывод. Остальной контент сайта не переписывался.

## Как работает схема

1. Нажатие на любой узел меняет выбранный этап, текст в центре, подробное описание и результат этапа.
2. «Показать цикл» запускает один проход: по 4,8 секунды на каждый из четырёх этапов. Маркер движется по связи к следующему узлу, линия показывает пройденный путь.
3. После четвёртого этапа маркер возвращается к вопросу. Появляется объяснение следующего цикла; показ останавливается, доступно повторение.
4. «Пауза» и «Продолжить» сохраняют текущую позицию. «Дальше» переключает этап вручную, «Начать сначала» возвращает к первому этапу.
5. При уходе со схемы или скрытии вкладки показ приостанавливается. Автоматического запуска при прокрутке нет.
6. Enter и Space активируют кнопки; стрелки, Home и End позволяют выбирать узлы с клавиатуры.

Значки обозначают этапы и остаются на своих местах. Движется маркер по направлению процесса. Фотографий, вымышленных финансовых показателей и клиентских результатов в схеме нет. Короткие подписи «На выходе» поясняют существующие этапы.

При reduced-motion автоматический показ недоступен, остаются выбор узлов и пошаговое управление без движения. Без JavaScript показаны все четыре этапа с исходными текстами.
