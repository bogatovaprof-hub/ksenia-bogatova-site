## 2. Реализованные требования

- CSS вынесен из `index.html` в один внешний файл.
- Итоговые значения повторно переопределявшихся hero-селекторов сведены в единый компонентный каскад.
- Основной JavaScript вынесен во внешний файл без изменения поведения диалога.
- Создана централизованная публичная конфигурация с development-маркерами и отключённой аналитикой.
- Удалены большой inline `<style>` и inline `<script>`.
- CSP больше не требует `unsafe-inline` для CSS и JavaScript.
- `noindex, nofollow` и `connect-src 'none'` сохранены.
- Публичный текст, структура body и композиция первого экрана не изменены.
- Созданы реестры блокеров и статусов материалов.
- Новые смысловые секции v5.0 не добавлялись.
