# Компактная схема финансовой системы

Дата: 2026-09-03. Статус: PASS.

В `assets/css/system-cycle.css` добавлена компактная раскладка для ширины от 960 px. Уменьшены заголовок, вертикальные отступы и резерв высоты в пояснении. Размер круга зависит от высоты окна, от 350 до 460 px. Текст состояния сохраняется для скринридера, визуально этап уже указан в центре и справа.

HTML, тексты, JavaScript и оформление остальных разделов не изменены. До изменения заголовок, большой круг и пустое пространство пояснений вытесняли нижние узлы за пределы экрана. Исправление ограничено CSS этого раздела.

## Проверки

В браузере проверены размеры 320×720, 390×844, 768×1024, 1024×768, 1280×720, 1366×768, 1440×900, 1920×1080. Горизонтального переполнения нет. Все четыре этапа переключаются, их названия помещаются в центре, круговые кнопки и управление не меньше 44×44 px. Дополнительно проверено длинное название «Правила и автоматизация» на телефоне и малых десктопах.

| Десктоп | Диаметр области круга | Нижняя граница всей интерактивной схемы при переходе по якорю |
| --- | ---: | ---: |
| 1024×768 | 408 px | 765,6 px |
| 1280×720 | 360 px | 701,7 px |
| 1366×768 | 408 px | 749,7 px |
| 1440×900 | 460 px | 801,7 px |
| 1920×1080 | 460 px | 801,7 px |

Во всех перечисленных десктопных размерах целиком видны круг, его подписи, кнопки и пояснение. На 1366×768 выполнена визуальная проверка. После запуска цикл прошёл полный оборот: сигнал достиг 360°, выбран этап 0, показано «Возвращаемся к вопросу». Проверены сброс и переход ArrowRight с переводом фокуса к следующему узлу.

На телефонах сохраняется вертикальная компоновка; требование одного экрана проверялось для десктопа. Реальные мобильные устройства, Safari, Firefox, скринридер и системный масштаб текста отдельно не проверялись. Фиксированной высоты и обрезания графики не добавлено. Правила prefers-reduced-motion сохранены. Отступлений от запроса по размещению круга не выявлено.
